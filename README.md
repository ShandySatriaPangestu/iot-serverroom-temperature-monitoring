# iot-serverroom-temperature-monitoring
IoT Server Room Temperature &amp; Monitoring System  Sistem pemantauan lingkungan server room berbasis IoT (Internet of Things) menggunakan ESP32. Proyek ini dirancang untuk mendeteksi suhu, kelembapan, dan potensi kebocoran/air secara real-time, serta dilengkapi dengan sistem web dashboard dan otomatisasi notifikasi darurat langsung ke Telegram.
